## 🏗️ Project Overview
This repository focuses on **Data Chunking**, the second critical phase of a Retrieval-Augmented Generation (RAG) pipeline. Large Language Models have strict context limits and token constraints. This project demonstrates how to use LangChain's **`CharacterTextSplitter`** to break massive, unstructured documents into manageable, uniform chunks based on precise character counts, ensuring they are ready for vector embedding.

---

## 🛠️ Key Technical Implementations

### 1. Length-Based Segmentation
* **Character Constraints:** Utilizing `chunk_size` to set a hard limit on how large each piece of text can be. This prevents API errors caused by exceeding an LLM's maximum context window.
* **Separator Configuration:** Defining specific separator strings (like `\n\n` for paragraphs or `\n` for lines) to dictate exactly *where* the splitter is allowed to make a cut.

### 2. Semantic Preservation
* **Chunk Overlap:** Implementing `chunk_overlap` to duplicate a small amount of text at the end of Chunk A and the beginning of Chunk B. This redundancy ensures that concepts spanning across a splitting boundary are not lost, preserving the semantic meaning for the AI.

### 3. Pipeline Readiness
* **Document Transformation:** Taking the single `Document` object generated by a Document Loader and transforming it into an array of smaller `Document` objects, perfectly formatted for insertion into a Vector Database.
